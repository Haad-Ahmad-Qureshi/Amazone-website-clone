# 🛒 Amazon Clone (Frontend Project)

This is a **frontend clone of Amazon's homepage** built using **HTML and CSS**.
The project focuses on layout design, responsiveness basics, and UI replication.

---

## 🚀 Live Demo

🔗 Deployed Link:**https://haad-ahmad-qureshi.github.io/Amazone-website-clone/**

---

## 📌 Features

* ✅ Amazon-like navigation bar
* ✅ Search bar with category dropdown
* ✅ Hero section with promotional message
* ✅ Product grid layout (shop section)
* ✅ Footer with multiple sections
* ✅ Hover effects and styling

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome (icons)
